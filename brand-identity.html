07 — Usage Rules

Do and don't

The brand is an asset. Protect its integrity in every context.

✓ Always do this

→ Use the full "StreamOps AI" name on first reference. Never abbreviate to "Streamops", "SOA", or "StreamAI".
→ Apply the logo on navy or charcoal backgrounds for primary placements.
→ Maintain minimum clear space around the logo equal to the height of the icon container.
→ Use Inter for all product and marketing typography.
→ Reserve JetBrains Mono exclusively for code and technical identifiers.
→ Use Electric Cyan (#00d4ff) for primary CTAs and interactive highlights only.

✕ Never do this

→ Do not change the logo colours or apply custom gradients to the wordmark.
→ Do not place the logo on busy photographic backgrounds without an overlay.
→ Do not use cyan as a background fill — it's an accent only.
→ Do not use multiple accent colours in the same sentence or UI element.
→ Do not use drop shadows heavier than the glow effect defined in the system.
→ Do not use the brand on a white background without the reversed logo variant.
Colour Hierarchy
Charcoal / Navy
Page and surface backgrounds. The majority of the screen should live here.
Cyan / Blue gradient
Primary CTAs, icon containers, gradient accents. Use sparingly — no more than one per screen section.
Cyan tint
Chip backgrounds, alert banners, hover states. The subtle version of the accent.
White
Headings and primary labels on dark surfaces only. Never as a background on dark-mode interfaces.
